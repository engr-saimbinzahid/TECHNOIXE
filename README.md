# TECHNOXIE Website

> **Technology Today, A Brighter Tomorrow**

A complete, production-ready multi-page website for **TECHNOXIE** — a full-service digital solutions and technology service provider.

---

## 🚀 Live Pages

| Page | File | Description |
|------|------|-------------|

## 🎨 Design System

- **Theme:** Dark futuristic technology (Navy/Black + Electric Blue + Purple)
- **Typography:** Outfit (headings), Inter (body), JetBrains Mono (labels)
- **Components:** Glassmorphism cards, gradient buttons, animated process steps
- **Animations:** Scroll reveal, counter animation, tilt effect, magnetic buttons, typing effect

---

## ⚙️ Tech Stack

- **HTML5** — Semantic, accessible, SEO-optimized
- **CSS3** — Custom properties, Flexbox, Grid, animations, glassmorphism
- **JavaScript ES6** — Intersection Observer, fetch API, form validation
- **Font Awesome 6** — Icon library (CDN)
- **Google Fonts** — Inter, Outfit, JetBrains Mono (CDN)

---

## 🔍 SEO Features

- Meta titles & descriptions on every page
- Open Graph tags for social sharing
- Schema.org structured data (SoftwareApplication)
- Semantic HTML5 elements
- Proper heading hierarchy (single H1 per page)
- Image alt text
- Lazy loading for images

## 🚀 Deployment

This is a static website. Deploy to any hosting platform:

1. **Netlify** — Drag and drop the folder
2. **Vercel** — Connect your Git repo
3. **GitHub Pages** — Push to a repo and enable Pages
4. **Shared Hosting** — Upload via FTP
